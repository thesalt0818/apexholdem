## 무엇이 들어 있나

- 로그인 / 회원가입, 프로필 (닉네임·아바타 변경)

- 카드 딜링·뒤집기·칩 이동·쇼다운 연출

- 액션 제한 시간, 딜러 버튼, 현재 족보 표시
